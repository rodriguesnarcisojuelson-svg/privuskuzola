# Fontes locais da Privus

Esta pasta contém as fontes Outfit e Cormorant Garamond, distribuídas através do Fontsource e utilizadas localmente pelo website.

Ambas são disponibilizadas nos termos da SIL Open Font License 1.1. As licenças integrais encontram-se nos ficheiros `OFL-Outfit.txt` e `OFL-Cormorant-Garamond.txt`.
